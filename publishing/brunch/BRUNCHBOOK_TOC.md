## 브런치북 정보

- 제목: 처음 시작하는 사람을 위한 ChatGPT 마스터 클래스
- 부제: 기능을 나열하지 않고, 실제 업무에 사용하는 순서대로 배우는 ChatGPT 입문서
- 기획 의도: ChatGPT를 처음 사용하는 독자가 기능을 단편적으로 익히는 데 그치지 않고, 이해·대화·조사·문서·자동화·이미지 활용의 순서로 기본기를 쌓도록 돕는다.
- 대상 독자: ChatGPT를 체계적으로 배우고 싶거나, 대화 기능만 사용하다가 업무 활용으로 확장하려는 실무자
- 구성: 4부 29편
- 주 CTA: 무료 ChatGPT 마스터 클래스
- 문의: hicrhodus@hicrhodus.com

## 공통 제작 기준

1. 원본 강의의 핵심 주장과 실제 사용 순서는 유지한다.
2. 강의 목차를 축약하지 않고 브런치 독자의 문제와 질문을 중심으로 재구성한다.
3. 글의 성격에 따라 관점·개념형, 기능·조작형, 실습·워크플로형과 비교·선택형을 구분한다.
4. 필요한 글에는 프롬프트, 화면 확인 기준, 완료 기준과 보안 주의사항을 포함한다.
5. 강의 요청·협업·기업 교육·컨설팅 문의 이메일을 글 말미에 배치한다.
6. 해당 회차의 YouTube 영상을 글의 마지막 요소로 배치한다.
7. GitHub 작업 브랜치와 Draft PR에서 검토한 뒤 승인된 원고만 정본으로 확정한다.
8. 제목은 `NN. 독립적으로 읽히는 제목` 형식으로 두 자리 순번을 붙인다.
9. 소제목은 글의 핵심 주장·독자 효용·실용 맥락 중 하나를 한 문장으로 표현한다.
10. 소제목에는 브런치북 제목인 `ChatGPT 마스터 클래스`를 반복하지 않는다.

# ChatGPT 이미지 생성 28｜업무에 바로 쓰는 이미지를 만드는 법

> 용도·구도·스타일·크기·문구를 구체적으로 설명해야 수정 횟수가 줄어듭니다

업무용 이미지는 단순히 ‘예쁘게 만들어 달라’고 해서 완성되지 않습니다. 어디에 쓸지, 무엇을 보여 줄지, 어떤 분위기와 비율이 필요한지, 이미지 안의 글자를 어떻게 처리할지 구체적으로 요청해야 합니다.

## 핵심 요약

* 이미지의 용도와 대상 매체를 먼저 정의합니다.
* 주제·구도·스타일·비율·텍스트 조건을 프롬프트에 담습니다.
* 브랜드·저작권·인물 표현을 확인하고 수정합니다.

## 검색 대신 원하는 장면을 설명하기

기존 이미지 검색은 이미 만들어진 자료 중에서 조건에 가까운 것을 찾는 방식입니다. 정확히 필요한 인물, 구도, 색상과 여백을 동시에 만족하는 이미지를 찾기 어렵고, 사용 권한도 따로 확인해야 합니다.

이미지 생성은 필요한 결과를 말로 설명해 초안을 만드는 방식입니다. 다만 생성했다고 자동으로 업무용 완성본이 되는 것은 아닙니다.

> 목적을 설명해 초안을 만들고, 결과를 검토한 뒤, 작은 수정으로 완성도를 높입니다.

## 이미지 생성을 시작하는 방법

현재 ChatGPT에서는 대화에서 원하는 이미지를 자연어로 요청하거나, 작성 화면의 이미지 생성 기능을 선택해 시작할 수 있습니다. 화면의 버튼 이름과 위치는 앱과 버전에 따라 달라질 수 있습니다.

기존 이미지를 바탕으로 만들고 싶을 때는 참조 이미지를 첨부하고 그 이미지가 어떤 역할을 하는지 설명합니다.

* 내용 참조: 인물, 제품이나 장면을 기준으로 사용
* 스타일 참조: 선, 질감, 색감과 분위기를 기준으로 사용
* 구도 참조: 배치, 여백과 카메라 각도를 기준으로 사용

참조 이미지를 사용할 권한이 있는지 먼저 확인하고, 고객·임직원의 얼굴이나 기밀 화면이 포함된 파일은 조직의 AI 사용 정책을 점검합니다.

## 막연한 요청이 실패하는 이유

다음 요청을 입력해 보겠습니다.

```text
AI 교육 PPT 표지 이미지 만들어 주세요.
```

ChatGPT는 다음 정보를 알 수 없습니다.

* 교육 대상이 누구인지
* 어떤 장면을 보여 줘야 하는지
* 사진인지 일러스트인지
* 제목을 넣을 공간이 어디인지
* 문서의 색상 체계가 무엇인지
* 로고나 글자를 넣어도 되는지
* 가로형인지 세로형인지

따라서 결과가 화려해 보여도 발표자료 표지로 바로 쓰기 어려울 수 있습니다. 좋은 요청은 ‘예쁘게’처럼 판단하기 어려운 표현보다 화면에서 확인할 수 있는 조건을 제공합니다.

## 업무용 이미지 프롬프트의 여섯 가지 요소

| 요소 | 설명 | 예시 |
| --- | --- | --- |
| 목적 | 이미지가 쓰일 곳과 대상 | 기업 임직원 대상 AI 교육 PPT 표지 |
| 장면 | 주요 대상과 행동, 배경 | 사무실에서 대시보드를 보는 직장인 |
| 스타일 | 표현 방식과 분위기 | 현대적이고 전문적인 기업용 일러스트 |
| 구도 | 위치, 여백, 카메라와 비율 | 인물은 오른쪽, 왼쪽 35%는 제목 여백, 16:9 |
| 색상 | 주조색과 포인트 색 | 블루-그레이, 청록색 포인트 |
| 제약 조건 | 반드시 제외하거나 지킬 항목 | 텍스트·로고·워터마크 제외 |

모든 요청에 여섯 요소를 기계적으로 길게 넣을 필요는 없습니다. 결과의 성공 여부를 바꾸는 조건만 구체적으로 적습니다.

## 실습: 발표자료 표지 이미지 만들기

이번 실습의 완료 기준은 다음과 같습니다.

* 16:9 가로형입니다.
* 인물이 오른쪽에 있습니다.
* 왼쪽에 제목을 넣을 충분한 여백이 있습니다.
* 전문적이고 차분한 기업용 분위기입니다.
* 이미지 안에 임의의 글자, 로고와 워터마크가 없습니다.

다음 프롬프트를 입력합니다.

```text
기업 임직원 대상 생성형 AI 교육의 프레젠테이션 표지 이미지를 만들어 주세요.

장면:
현대적인 사무실에서 직장인이 노트북으로 데이터 대시보드를 확인하고 있습니다.

스타일:
전문적이고 현대적인 기업용 일러스트
과장된 공상과학 분위기는 제외

구도:
직장인은 화면 오른쪽에 배치합니다.
왼쪽 35%는 제목을 넣을 수 있도록 단순한 배경과 여백으로 구성합니다.

색상:
차분한 블루-그레이 계열, 청록색 포인트

화면 비율:
16:9 가로형

제약 조건:
이미지 안에 텍스트, 로고, 워터마크를 넣지 마세요.
```

결과가 나오면 느낌만 보지 말고 완료 기준을 하나씩 확인합니다.

## 같은 대화에서 필요한 부분만 수정하기

첫 결과가 완벽하지 않아도 전체 프롬프트를 버리고 처음부터 다시 시작할 필요는 없습니다. 마음에 드는 요소를 유지하면서 한두 가지씩 수정합니다.

```text
현재 이미지의 인물과 전체 장면은 유지해 주세요.

다음 사항만 수정해 주세요.

1. 왼쪽 제목 여백을 조금 더 넓혀 주세요.
2. 전체 색상의 채도를 낮춰 차분한 분위기로 바꿔 주세요.

그 밖의 인물, 사무실 구조, 조명, 카메라 각도와 화면 비율은 바꾸지 마세요.
```

수정할 때는 **바꿀 것**과 **유지할 것**을 함께 적습니다. 여러 요소를 한꺼번에 바꾸면 어떤 지시가 결과에 영향을 줬는지 판단하기 어려우므로 작은 수정부터 진행합니다.

## 이미지 안의 텍스트 다루기

영상에서는 업무 이미지에 텍스트를 넣지 않고 PowerPoint 같은 편집 도구에서 나중에 추가하는 방식을 사용합니다. 철자, 줄바꿈과 배치를 정확히 관리하기 쉬운 안전한 방법입니다.

현재 이미지 생성 기능은 짧은 텍스트를 직접 넣는 요청도 지원합니다. 텍스트가 꼭 필요하면 정확한 문구를 따옴표로 표시하고 위치, 글꼴 분위기, 크기와 허용되는 다른 글자의 유무를 구체적으로 적습니다.

```text
이미지 상단 중앙에 “AI WORKSHOP”이라는 제목만 넣어 주세요.
흰색의 굵은 산세리프 글꼴로 한 줄에 표시합니다.
다른 텍스트, 숫자, 로고와 워터마크는 넣지 마세요.
```

중요한 제목, 수치와 제작용 문구는 결과의 모든 글자를 직접 검수합니다. 긴 문장이나 정확성이 중요한 타이포그래피는 이미지 생성 후 디자인 도구에서 마무리하는 편이 안전합니다.

## 실패한 결과를 수정하는 방법

| 문제 | 수정 방향 |
| --- | --- |
| 제목 여백이 부족함 | 인물 위치와 비어 있어야 할 영역의 비율을 지정 |
| 분위기가 지나치게 미래적임 | 원하는 기업용 스타일과 제외할 분위기를 함께 명시 |
| 임의의 글자·로고가 생김 | 텍스트, 로고, 워터마크 금지를 반복하고 결과를 검수 |
| 비율이 맞지 않음 | 16:9 가로형처럼 결과 비율을 명시 |
| 수정 후 인물과 구도가 달라짐 | 변경할 요소와 유지할 요소를 분리해 다시 요청 |
| 결과가 막연함 | 목적, 대상, 장면과 사용 위치를 먼저 구체화 |

‘더 예쁘게’처럼 모호한 반응보다 “왼쪽 여백을 넓혀 주세요”, “채도를 낮춰 주세요”처럼 확인 가능한 변경을 요청합니다.

## 업무용 이미지 검수

### 목적과 구도

* 표지, 보고서, 배너 등 사용 목적에 맞는가?
* 제목과 본문을 넣을 공간이 충분한가?
* 화면 비율과 해상도가 사용처에 맞는가?

### 시각적 오류

* 인물의 손, 얼굴과 물체가 부자연스럽지 않은가?
* 배경의 구조와 그림자가 모순되지 않는가?
* 의도하지 않은 글자, 로고와 워터마크가 없는가?

### 사실과 권리

* 생성 이미지를 실제 사건이나 실제 데이터의 증거처럼 사용하지 않았는가?
* 실제 수치를 보여 주는 차트는 원자료로 정확하게 만들었는가?
* 특정 브랜드, 캐릭터나 작가의 작품을 모방하지 않았는가?
* 실존 인물의 얼굴을 사용할 권한과 동의가 있는가?
* 조직의 공개·보안·브랜드 검토 절차를 거쳤는가?

## 실습 완료 기준

* 이미지의 목적과 대상을 설명했습니다.
* 장면, 스타일, 구도, 색상과 제약 조건을 지정했습니다.
* 원하는 화면 비율과 제목 여백을 확인했습니다.
* 첫 결과를 완료 기준에 따라 검수했습니다.
* 같은 대화에서 한두 요소만 수정했습니다.
* 수정할 것과 유지할 것을 함께 지시했습니다.
* 텍스트, 로고, 시각적 오류와 권리 문제를 확인했습니다.

## 핵심 정리

* 이미지 생성은 검색 결과를 고르는 일이 아니라 필요한 장면을 설명해 초안을 만드는 일입니다.
* 막연한 요청은 사용 목적과 성공 기준이 없어 업무용 결과로 이어지기 어렵습니다.
* 목적, 장면, 스타일, 구도, 색상과 제약 조건을 조합합니다.
* 결과를 한 번에 완성하려 하지 말고 작은 수정으로 개선합니다.
* 수정할 때는 바꿀 것과 유지할 것을 함께 적습니다.
* 이미지 안의 텍스트는 짧게 요청하고 모든 글자를 검수합니다.
* 업무에 사용하기 전 시각적 오류, 사실성, 권리와 보안을 사람이 확인합니다.

현재 이미지 생성과 수정 방법은 [OpenAI이미지 생성 공식 가이드](https://learn.chatgpt.com/docs/image-generation)에서 확인할 수 있습니다.

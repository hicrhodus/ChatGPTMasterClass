## 네이버용 제작 원칙

1. 브런치 원고를 그대로 복사하지 않고 검색자의 질문에 바로 답하는 글로 다시 쓴다.
2. 제목은 핵심 검색어를 앞에 두고 두 자리 순번을 유지한다.
3. 첫 3~5문장에서 글의 결론과 독자가 얻을 내용을 제시한다.
4. 본문은 검색 의도와 글의 성격에 맞춰 요약, 단계별 설명, 화면 또는 사례, 실습 프롬프트와 확인 기준을 선택·구성한다.
5. FAQ는 공통 필수 요소로 사용하지 않는다. 본문에서 자연스럽게 해결하기 어려운 실제 검색 질문이 여러 개 있을 때만 선택적으로 넣는다.
6. 기존 GitHub 이미지만 사용하고, 없는 화면을 임의로 만들지 않는다.
7. 태그는 핵심어와 브랜드어를 합쳐 5~8개를 사용한다.
8. 글 말미에 히크로도스 소개, 무료 강의, 이메일 문의, 해당 회차 YouTube 영상을 둔다.
9. 홍보 문구는 본문 효용을 해치지 않도록 결론 뒤에 한 번만 배치한다.
10. 기능·화면·플랜은 발행 직전 최신 공식 안내와 실제 화면을 확인한다.
11. GitHub Draft PR에서 검토한 뒤 승인된 글만 네이버 임시저장으로 옮긴다.
12. 네이버 공개 발행과 예약 발행은 사용자가 직접 결정한다.
13. 대량 등록은 피하고, 골든샘플 승인 후 3~5편 단위로 순차 제작한다.

## 골든샘플 검토 기준

- 제목만 읽어도 검색 의도와 회차를 알 수 있는가
- 첫 문단에서 답을 먼저 제시하는가
- 경험과 전문성이 과장 없이 드러나는가
- 독자가 바로 실행할 프롬프트와 확인 기준이 있는가
- 이미지가 장식이 아니라 이해를 돕는가
- 불필요한 고정 섹션이 반복되지 않고 글의 성격에 맞는 구성을 사용했는가
- CTA가 자연스럽고 한 번만 제시되는가
- 이메일과 YouTube 영상이 글 마지막에 정확히 배치됐는가

## 승인 후 생산 순서

01·02 골든샘플 형식 승인 후 브런치의 03~29 순서를 그대로 유지한다. 네이버용 제목과 본문은 검색 의도에 맞춰 별도로 최적화한다. 03~05를 첫 후속 묶음으로 제작하며, 이후에도 3~5편씩 Draft PR과 임시저장 단위로 진행한다.

# 06-2. 코드 블록: 다이어그램을 미리 보고, Python을 직접 실행하기

## 1. 이 강의에서 배울 내용

ChatGPT가 만든 코드는 개발자만을 위한 결과물이 아닙니다. 코드를 직접 작성하지 못해도 업무 절차를 다이어그램으로 만들거나, 간단한 계산을 실행해 결과를 확인하는 데 활용할 수 있습니다.

이 강의에서는 다음 내용을 익힙니다.

* 일반 답변과 코드 블록의 차이를 이해합니다.
* Mermaid 코드로 업무 흐름도를 만듭니다.
* 지원되는 환경에서 Preview로 다이어그램을 확인합니다.
* Python 코드로 합계와 평균을 계산합니다.
* 지원되는 환경에서 Run으로 코드를 실행하고 결과를 검산합니다.
* Preview나 Run이 보이지 않거나 코드가 실패할 때 대처합니다.
* 업무 데이터와 코드를 다룰 때 지켜야 할 보안 원칙을 확인합니다.

> 영상 촬영 이후 ChatGPT의 화면이나 버튼 위치가 변경될 수 있습니다. 이 강의에서는 특정 버튼의 위치보다 요청 → 코드 확인 → 결과 확인 → 수정의 사용 원칙을 중심으로 학습합니다.

## 2. 비개발자에게도 코드 블록이 필요한 이유

코드가 일반 답변의 설명과 뒤섞이면 어디부터 어디까지가 실행할 내용인지 구분하기 어렵습니다. 복사할 때 설명까지 함께 선택되거나, 문법의 줄바꿈과 들여쓰기가 깨질 수도 있습니다.

코드 블록은 코드와 설명을 분리해 다음 작업을 쉽게 만듭니다.

* 코드만 읽고 복사합니다.
* 사용된 언어를 확인합니다.
* 필요한 줄을 찾아 수정합니다.
* 오류 메시지와 코드를 함께 비교합니다.
* 지원되는 형식은 결과를 미리 봅니다.
* 지원되는 Python 코드는 직접 실행해 결과를 확인합니다.

비개발자는 문법을 처음부터 외울 필요가 없습니다. 만들고 싶은 결과와 조건을 자연어로 설명하고, ChatGPT가 만든 코드가 의도한 결과를 내는지 확인하는 데 집중하면 됩니다.

## 3. Code, Preview와 Run의 차이

코드 블록에서 보이는 기능은 코드 유형, 플랜, 기기, 모델과 워크스페이스 정책에 따라 달라질 수 있습니다.

| 기능 | 하는 일 | 확인할 내용 |
| --- | --- | --- |
| Code | 생성된 코드 원문을 표시 | 언어, 단계, 변수와 조건이 요청과 일치하는가? |
| Preview | 지원되는 코드를 시각적 결과로 표시 | 흐름, 배치와 분기가 의도와 일치하는가? |
| Run | 지원되는 Python 코드를 실행 | 출력값과 오류가 예상과 일치하는가? |

화면에 따라 “Code”는 “코딩” 또는 “코드 보기”, “Run”은 “실행” 또는 “실행됨”으로 표시될 수 있습니다. Python 실행 결과가 표시되는 영역은 “Console” 또는 “콘솔”로 나타날 수 있습니다.

Preview와 Run은 서로 다른 기능입니다.

* Preview는 Mermaid 다이어그램이나 HTML처럼 시각적으로 확인할 수 있는 코드에 적합합니다.
* Run은 계산이나 데이터 처리처럼 실행 결과를 확인할 수 있는 Python 코드에 적합합니다.

모든 코드 블록에서 두 기능이 모두 나타나는 것은 아닙니다. 버튼이 보이지 않는다고 해서 프롬프트나 코드가 잘못된 것은 아닐 수 있습니다.

## 4. 코드 블록을 활용하는 기본 흐름

코드 블록은 다음 순서로 사용합니다.

> 결과 설명 → 코드 생성 → 코드 구조 확인 → Preview 또는 Run → 결과 검토 → 부분 수정 → 다시 확인

1. 만들고 싶은 결과를 말로 설명합니다.
2. 사용할 언어 또는 형식을 지정합니다.
3. 반드시 포함할 단계와 조건을 적습니다.
4. 생성된 코드에서 누락된 내용이 없는지 확인합니다.
5. 지원되는 경우 Preview 또는 Run으로 결과를 확인합니다.
6. 틀린 부분만 구체적으로 지정해 수정합니다.
7. 결과를 다시 확인하고 업무에 맞게 저장하거나 복사합니다.

핵심은 코드를 한 번 생성하는 것이 아니라, 눈으로 확인하고 필요한 부분만 고치는 것입니다.

## 5. Mermaid로 업무 다이어그램 만들기

Mermaid는 텍스트로 흐름도, 순서도와 같은 다이어그램을 표현하는 문법입니다. 복잡한 디자인 도구를 열기 전에 업무 절차나 아이디어의 구조를 빠르게 시각화할 때 유용합니다.

이번 실습에서는 고객 문의 처리 절차를 흐름도로 만듭니다.

<pre><code>다음 고객 문의 처리 절차를 Mermaid flowchart 코드로 만들어 주세요.

절차:
1. 고객 문의 접수
2. 문의 유형 확인
3. 단순 문의는 상담원이 직접 답변
4. 기술 문의는 담당 부서에 전달
5. 담당 부서가 답변 초안 작성
6. 상담원이 답변을 검토하고 고객에게 발송
7. 처리 결과를 CRM에 기록

조건:
- 단순 문의와 기술 문의의 분기 조건이 보이게 작성해 주세요.
- 각 단계의 이름은 짧게 작성해 주세요.
- Mermaid 코드 블록으로 출력해 주세요.</code></pre>

결과가 생성되면 먼저 Code 영역을 확인합니다.

* 코드 블록의 언어가 Mermaid로 표시되는가?
* 문의 접수와 유형 확인 단계가 있는가?
* 단순 문의와 기술 문의가 분리되어 있는가?
* 두 경로가 답변 발송과 CRM 기록으로 이어지는가?

코드를 이해하기 어렵더라도 단계 이름과 연결 순서를 읽으면 기본 구조를 점검할 수 있습니다.

## 6. Preview로 다이어그램 확인하기

사용 중인 환경에서 Mermaid 미리보기를 지원한다면 Preview를 열어 실제 흐름도를 확인합니다.

다음 항목을 점검합니다.

1. 시작점과 종료점이 분명한가?
2. 절차가 위에서 아래 또는 왼쪽에서 오른쪽으로 자연스럽게 이어지는가?
3. 분기 기준이 질문 형태로 명확하게 표시되는가?
4. 단순 문의와 기술 문의의 경로가 뒤바뀌지 않았는가?
5. 같은 단계가 불필요하게 반복되지 않는가?
6. 한 화면에서 읽을 수 있을 정도로 간결한가?

전체 화면 보기가 제공되면 다이어그램을 크게 열어 확인할 수 있습니다. 확대·축소와 화면 이동을 사용해 작은 노드를 살펴보고, 코드 표시와 미리보기를 오가며 어떤 코드가 어떤 그림으로 표현되는지 비교합니다.

다이어그램이 너무 복잡하다면 전체를 처음부터 다시 만들기보다 수정할 조건을 지정합니다.

<pre><code>현재 Mermaid 흐름도를 수정해 주세요.

- 전체 단계는 5개 이하로 줄여 주세요.
- 기술 문의 분기는 유지해 주세요.
- 마지막에는 모든 경로가 CRM 기록 단계로 합쳐지게 해 주세요.
- 기존 코드 블록 안에서 수정해 주세요.</code></pre>

이 방식은 회의에서 논의할 프로세스 초안, 고객 대응 절차, 승인 흐름과 콘텐츠 제작 과정을 빠르게 검토할 때 활용할 수 있습니다.

## 7. Mermaid 결과가 나오지 않을 때

Preview가 보이지 않거나 다이어그램이 깨지면 다음 순서로 점검합니다.

| 상황 | 가능한 원인 | 해결 방법 |
| --- | --- | --- |
| Preview가 없음 | 해당 코드 유형이나 사용 환경이 미리보기를 지원하지 않음 | Mermaid 코드를 복사해 지원되는 편집기에서 확인 |
| 문법 오류가 표시됨 | 노드 이름, 괄호 또는 연결 문법이 잘못됨 | 오류 메시지를 붙여 넣고 해당 줄만 수정 요청 |
| 분기가 잘못 연결됨 | 자연어 절차의 조건이 모호함 | 분기 질문과 각 경로의 결과를 명시 |
| 흐름도가 너무 큼 | 단계와 설명이 지나치게 많음 | 단계 수와 노드 글자 수를 제한 |
| 한글이 깨짐 | 사용 도구의 글꼴 또는 인코딩 문제 | 노드 이름을 짧게 바꾸거나 다른 지원 도구에서 확인 |

오류가 발생하면 오류 메시지를 추측해 요약하지 말고 그대로 전달합니다.

<pre><code>다음 Mermaid 오류 메시지를 기준으로 코드를 수정해 주세요.

[오류 메시지 붙여넣기]

요청:
- 오류가 난 원인을 한 문장으로 설명해 주세요.
- 문제가 있는 부분만 수정해 주세요.
- 수정된 전체 코드를 다시 보여 주세요.</code></pre>

## 8. Python 코드로 계산 검산하기

ChatGPT가 계산한 숫자는 그럴듯해 보여도 틀릴 수 있습니다. 간단한 합계나 평균은 Python 코드로 계산 과정을 남기고, 지원되는 환경에서는 직접 실행해 검산할 수 있습니다.

이번 실습에서는 1월부터 4월까지의 월별 매출 합계와 평균을 계산합니다.

<pre><code>아래 월별 매출 데이터의 합계와 평균을 계산하는 Python 코드를 작성해 주세요.

1월: 1200
2월: 1500
3월: 1800
4월: 1600

조건:
- 총매출과 평균 매출을 print로 출력해 주세요.
- 변수명은 의미를 알 수 있게 작성해 주세요.
- 외부 라이브러리를 사용하지 마세요.
- Python 코드 블록으로 출력해 주세요.</code></pre>

생성된 코드는 다음과 같은 구조인지 확인합니다.

<pre><code>monthly_sales = [1200, 1500, 1800, 1600]

total_sales = sum(monthly_sales)
average_sales = total_sales / len(monthly_sales)

print("총매출:", total_sales)
print("평균 매출:", average_sales)</code></pre>

코드를 읽을 때는 문법보다 다음 세 가지를 먼저 봅니다.

* 입력값 네 개가 정확한가?
* 합계가 네 값을 모두 더하도록 작성되었는가?
* 평균의 분모가 데이터 개수인 4인가?

## 9. Run으로 실행 결과 확인하기

사용 환경에서 Python 실행을 지원한다면 Run을 눌러 결과를 확인합니다.

예상 결과는 다음과 같습니다.

<pre><code>총매출: 6100
평균 매출: 1525.0</code></pre>

영상의 후속 실습처럼 코드에서 1월 매출 1200을 2100으로 직접 바꾼 뒤 다시 실행할 수도 있습니다. 이때 예상 결과는 총매출 7000, 평균 매출 1750.0입니다. 코드를 생성한 뒤에도 값을 직접 편집하고 재실행할 수 있다는 점이 코드 블록의 중요한 장점입니다.

실행 결과가 예상과 다르면 다음 항목을 확인합니다.

1. 입력한 숫자가 원자료와 같은가?
2. 합계에서 빠진 값이 없는가?
3. 평균을 구할 때 데이터 개수가 정확한가?
4. 문자열과 숫자를 혼합하지 않았는가?
5. 실행한 코드가 가장 최근에 수정한 버전인가?

오류가 발생하면 다음과 같이 요청합니다.

<pre><code>다음 Python 코드와 오류 메시지를 기준으로 문제를 수정해 주세요.

[현재 Python 코드 붙여넣기]

[오류 메시지 붙여넣기]

요청:
- 오류 원인을 초보자도 이해할 수 있게 설명해 주세요.
- 입력 데이터와 계산 목적은 바꾸지 마세요.
- 수정된 전체 코드를 다시 작성해 주세요.</code></pre>

Run은 계산을 검토하는 보조 수단입니다. 회계, 세무, 급여, 계약 금액처럼 중요한 숫자는 원자료와 조직의 공식 시스템에서 다시 확인해야 합니다.

## 10. 코드 실행이 제한될 때의 대안

Run 버튼이 보이지 않거나 실행이 제한될 수 있습니다. 코드 유형, 플랜, 모델, 기기와 회사 워크스페이스의 보안 정책이 원인일 수 있습니다.

이 경우 다음 방법을 사용합니다.

* ChatGPT에 코드의 계산 과정을 줄별로 설명하도록 요청합니다.
* 입력값과 예상 결과를 표로 정리해 수동으로 대조합니다.
* 조직에서 승인한 Python 환경이나 노트북에서 실행합니다.
* Excel이나 Google Sheets의 수식으로 다시 계산합니다.
* 중요한 계산은 담당 부서의 공식 도구로 최종 검증합니다.

<pre><code>이 Python 코드를 실행하지 말고 계산 과정을 검토해 주세요.

1. 입력값을 표로 정리해 주세요.
2. 합계 계산식을 보여 주세요.
3. 평균의 분모가 맞는지 확인해 주세요.
4. 예상 출력값을 제시해 주세요.
5. 잘못될 수 있는 지점을 표시해 주세요.</code></pre>

## 11. 실무에서 활용하기

코드 블록은 다음과 같은 업무에 적용할 수 있습니다.

### 11.1 업무 프로세스 시각화

* 고객 문의 처리 흐름
* 품의와 결재 절차
* 신규 입사자 온보딩
* 콘텐츠 제작과 검수
* 장애 접수와 대응

### 11.2 간단한 계산 검산

* 월별 합계와 평균
* 목표 대비 달성률
* 항목별 비중
* 단순 증감률
* 설문 응답 집계

### 11.3 데이터 처리 초안

* CSV 열 이름 확인
* 중복 행 탐색
* 결측치 개수 확인
* 날짜 형식 통일
* 범주별 건수 집계

업무에 적용할 때는 작은 샘플로 먼저 실행하고, 결과가 맞는 것을 확인한 뒤 범위를 넓힙니다.

## 12. 보안과 개인정보 주의사항

코드와 데이터에는 민감한 정보가 포함될 수 있습니다. 조직의 승인 없이 다음 정보를 입력하지 않습니다.

* 고객과 임직원의 개인정보
* 비밀번호, API 키와 인증 토큰
* 비공개 계약 조건과 단가
* 내부 서버 주소와 보안 설정
* 미공개 매출과 재무 정보
* 회사의 소스 코드와 영업 비밀

실습에서는 실제 자료 대신 가상의 이름과 숫자를 사용합니다. 회사 자료가 꼭 필요하다면 최소한의 항목만 남기고 익명화한 뒤, 조직에서 승인한 환경과 보안 정책을 따릅니다.

ChatGPT가 만든 코드는 실행 전에 읽어 봅니다. 파일 삭제, 외부 전송, 시스템 변경처럼 영향을 주는 명령이 포함되어 있다면 실행하지 말고 담당자에게 확인합니다.

## 13. 실습하기

### 13.1 업무 흐름도 만들기

1. 고객 문의 처리 프롬프트를 입력합니다.
2. Mermaid 코드 블록이 생성되는지 확인합니다.
3. 분기 조건과 단계 연결을 점검합니다.
4. 지원되는 경우 Preview를 엽니다.
5. 단계를 5개 이하로 줄이는 수정 요청을 입력합니다.
6. 수정된 흐름을 다시 확인합니다.

### 13.2 계산 검산하기

1. 월별 매출 계산 프롬프트를 입력합니다.
2. 네 개의 입력값과 계산식을 확인합니다.
3. 지원되는 경우 Run을 실행합니다.
4. 총매출 6100, 평균 1525.0이 나오는지 확인합니다.
5. 1월 매출을 1200에서 2100으로 바꿉니다.
6. 다시 실행해 총매출 7000, 평균 1750.0이 나오는지 확인합니다.

* 자연어 절차를 Mermaid 코드 블록으로 만들었다.
* 단순 문의와 기술 문의의 분기를 확인했다.
* 지원되는 경우 Preview에서 흐름도를 확인했다.
* 복잡한 흐름도를 조건을 지정해 단순화했다.
* 월별 매출을 계산하는 Python 코드를 만들었다.
* 입력값, 합계와 평균 계산식을 확인했다.
* 지원되는 경우 Run에서 출력값을 확인했다.
* 오류 메시지를 기준으로 수정하는 프롬프트를 사용할 수 있다.
* 중요한 계산은 별도로 검증해야 하는 이유를 설명할 수 있다.
* 코드와 데이터에 민감한 정보를 넣지 않았다.

## 15. 핵심 정리

* 코드 블록은 코드와 설명을 분리해 복사, 수정과 검토를 쉽게 만듭니다.
* 비개발자도 자연어로 결과를 설명하고 코드의 결과를 확인하는 방식으로 활용할 수 있습니다.
* Mermaid와 Preview는 업무 절차를 빠르게 시각화하는 데 유용합니다.
* Python과 Run은 간단한 계산의 과정을 남기고 결과를 검산하는 데 유용합니다.
* 생성된 코드를 직접 편집하고 다시 실행하면서 결과의 변화를 확인할 수 있습니다.
* Preview와 Run의 제공 여부는 코드 유형과 사용 환경에 따라 달라질 수 있습니다.
* 오류가 나면 오류 메시지를 그대로 제공하고 문제가 있는 부분만 수정하도록 요청합니다.
* AI가 만든 코드와 실행 결과는 최종 검증을 대신하지 않습니다.
* 작은 샘플로 먼저 확인하고, 중요한 숫자는 공식 시스템과 원자료로 다시 검토합니다.
* 개인정보, 회사 기밀과 인증 정보는 코드나 프롬프트에 입력하지 않습니다.

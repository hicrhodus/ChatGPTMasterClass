# 08-2. 이미지 편집과 검수: 바꿀 것은 바꾸고 지킬 것은 지키기

## 1. 이 강의에서 배울 내용

실무에서는 이미지를 처음부터 만드는 일만큼 기존 이미지의 일부를 수정하는 일이 많습니다. 전체적으로 마음에 드는 이미지에서 배경의 소품 하나를 빼거나, 벽면에 요소 하나만 추가하려고 처음부터 다시 생성하면 인물과 구도까지 함께 바뀔 수 있습니다.

이 강의에서는 기존 이미지를 분석하고 필요한 영역만 편집한 뒤 실무 사용 전에 검수하는 흐름을 익힙니다.

* 이미지 입력과 이미지 편집의 차이를 이해합니다.
* 바로 수정하기 전에 원본의 구조를 분석합니다.
* 변경할 요소와 유지할 요소를 나눠서 요청합니다.
* 선택 영역 또는 자연어 지시로 부분 편집합니다.
* 원본과 편집본을 비교하고 작은 수정으로 개선합니다.
* 발표자료, 보고서와 배너에 활용합니다.
* 사실성, 인물, 저작권, 상표와 보안을 검수합니다.

## 2. 이미지 분석과 편집의 차이

이미지를 첨부하는 목적은 두 가지로 나눌 수 있습니다.

| 목적 | 사용 방식 | 결과 |
| --- | --- | --- |
| 이미지 입력·분석 | 화면, 사진, 도표의 내용을 설명하거나 비교 | 텍스트 분석과 판단 |
| 이미지 생성·편집 | 기존 이미지를 바탕으로 일부 또는 전체를 변경 | 새로운 이미지 결과 |

이미지를 올리기만 하지 말고 ChatGPT가 무엇을 살펴보고 어떤 결과를 만들어야 하는지 프롬프트에 적습니다.

## 3. 편집 전에 원본을 분석하는 이유

부분 편집의 핵심은 무엇을 바꿀지보다 무엇을 지킬지 명확히 하는 것입니다. 먼저 원본의 구조를 정리하면 유지 조건을 빠뜨릴 가능성이 줄어듭니다.

다음 항목을 확인합니다.

* 주요 피사체와 위치
* 배경과 사물의 관계
* 카메라 각도와 화면 비율
* 광원, 그림자와 색상
* 반드시 유지할 요소
* 수정 가능한 영역

분석 결과도 틀릴 수 있으므로 원본과 대조합니다. 특히 사람의 얼굴, 제품 세부 정보와 작은 글자는 직접 확인합니다.

## 4. 편집의 기본 구조

좋은 편집 요청은 네 부분으로 구성할 수 있습니다.

1. **대상:** 어느 이미지를 편집하는가?
2. **변경:** 정확히 무엇을 바꾸는가?
3. **유지:** 어떤 요소는 그대로 남겨야 하는가?
4. **제외:** 새로 만들면 안 되는 요소는 무엇인가?

예를 들어 “벽면을 고쳐 주세요”보다 “오른쪽 벽면에 포스터를 추가하고 인물·조명·카메라 각도는 유지해 주세요”가 결과를 확인하기 쉽습니다.

## 5. 실습 1: 원본 이미지 분석

편집할 권한이 있는 사무실 사진이나 이전 강의에서 직접 생성한 이미지를 사용합니다. 실제 임직원이나 고객의 얼굴, 기밀 문서와 개인 화면이 포함된 이미지는 올리지 않습니다.

먼저 이미지를 첨부하고 분석만 요청합니다.

<pre><code>이 이미지를 바로 수정하지 말고 먼저 분석해 주세요.

다음 항목으로 정리해 주세요.

1. 주요 피사체
2. 배경
3. 카메라 각도
4. 광원과 그림자
5. 주요 색상
6. 반드시 유지해야 할 요소
7. 수정 가능한 영역

잘 보이지 않는 부분은 추정하지 말고 확인이 어렵다고 표시해 주세요.</code></pre>

분석 결과가 나오면 원본과 비교해 유지 요소 목록을 확정합니다.

## 6. 실습 2: 오른쪽 벽면만 수정하기

이번 실습의 목표는 오른쪽 벽면에 데이터 대시보드 포스터를 추가하면서 인물과 전체 장면을 유지하는 것입니다.

선택 도구가 제공되는 환경에서는 수정할 영역을 먼저 선택할 수 있습니다. 선택 영역은 정확한 경계가 아니라 편집 의도를 전달하는 보조 수단이므로, 자연어로 대상 위치와 유지 조건을 함께 적습니다. 선택 도구를 쓰지 않고 대화에서 직접 편집을 요청할 수도 있습니다.

<pre><code>업로드한 이미지에서 오른쪽 벽면만 수정해 주세요.

변경할 요소:
- 오른쪽 벽면에 기업용 데이터 대시보드 포스터 추가
- 포스터는 청록색과 남색을 사용
- 실제 글자는 사용하지 않고 단순한 차트 형태로 표현

유지할 요소:
- 인물의 얼굴, 자세와 복장
- 카메라 각도와 화면 비율
- 사무실 구조
- 기존 조명과 그림자
- 그 밖의 모든 물체와 색상

추가 인물, 로고, 텍스트와 워터마크는 생성하지 마세요.</code></pre>

## 7. 원본과 편집본 비교하기

편집 결과를 원본과 나란히 놓고 다음을 확인합니다.

### 요청한 변경

* 오른쪽 벽면에만 포스터가 추가됐는가?
* 포스터의 색상과 차트 형태가 요청과 맞는가?
* 원근, 조명과 그림자가 주변 공간에 자연스럽게 맞는가?

### 유지 조건

* 인물의 얼굴, 자세와 복장이 유지됐는가?
* 카메라 각도와 화면 비율이 같아 보이는가?
* 사무실 구조와 다른 물체가 바뀌지 않았는가?
* 의도하지 않은 글자, 로고나 인물이 생기지 않았는가?

원본과 차이가 크면 유지 조건을 더 구체적으로 적어 다시 요청합니다. 편집을 반복할수록 작은 변화가 누적될 수 있으므로 중요한 유지 조건은 매 요청에서 반복합니다.

<pre><code>포스터의 크기만 현재의 80%로 줄여 주세요.

인물, 얼굴, 자세, 복장, 카메라 각도, 사무실 구조, 조명, 그림자, 색상과 화면 비율은 직전 이미지 그대로 유지해 주세요.
그 밖의 부분은 변경하지 마세요.</code></pre>

## 8. 실무 활용 1: 보고서용 업무 절차 이미지

업무 절차를 설명하는 이미지는 개념을 빠르게 보여 주는 데 유용합니다. 실제 단계명과 수치는 이미지 안에 생성하기보다 문서 편집 도구에서 정확하게 추가할 수 있습니다.

<pre><code>보고서에 넣을 업무 절차 안내 이미지를 만들어 주세요.

주제:
데이터 수집부터 의사결정까지 다섯 단계로 이어지는 업무 흐름

스타일:
미니멀 기업용 벡터 일러스트

구성:
다섯 개의 단순한 아이콘을 화살표로 연결합니다.
단계 이름 같은 글자는 넣지 않고 아이콘과 화살표만 표현합니다.

색상:
블루-그레이 계열, 청록색 포인트

제약 조건:
이미지 안에 텍스트, 숫자, 로고와 워터마크를 넣지 마세요.</code></pre>

생성된 이미지는 절차를 설명하는 삽화입니다. 실제 데이터나 성과를 보여 주는 차트는 원자료를 바탕으로 Excel 같은 도구에서 정확하게 만듭니다.

## 9. 실무 활용 2: 마케팅 배너 초안

배너는 콘셉트와 여백을 빠르게 검토하는 초안으로 활용할 수 있습니다.

<pre><code>업무 자동화 솔루션을 소개하는 디지털 배너 이미지를 만들어 주세요.

대상:
업무 자동화에 관심 있는 직장인

핵심 메시지:
반복 업무를 줄이고 데이터 기반 업무 시간을 확보합니다.

비주얼 콘셉트:
데이터 대시보드와 AI 업무 도우미가 자연스럽게 결합된 장면

스타일:
전문적이고 신뢰감 있는 기업용 비주얼
과도한 공상과학 분위기는 제외

구도:
오른쪽에 주요 장면을 배치하고, 왼쪽에는 광고 문구를 넣을 공간을 확보합니다.

제약 조건:
텍스트, 브랜드 로고와 워터마크를 넣지 마세요.</code></pre>

실제 광고 문구는 디자인 도구에서 추가하고, 외부 공개 전에 브랜드와 법무 검토가 필요한지 확인합니다.

## 10. 사용 전 마지막 검수

### 10.1 사실과 이미지 구분

생성 이미지는 실제 사건이나 실제 데이터를 증명하는 자료가 아닙니다. 보고서에서는 설명과 개념 시각화 용도로 사용하고, 실제 사실을 전달할 때는 출처가 확인된 사진, 원자료 기반 차트나 실제 화면을 사용합니다.

### 10.2 인물과 개인정보

실존 인물을 편집하거나 닮은 이미지를 사용할 때는 당사자의 동의와 사용 권한을 확인합니다. 고객, 임직원과 미성년자의 얼굴이나 개인정보가 포함된 이미지를 업로드하기 전에 조직의 정책을 점검합니다.

### 10.3 저작권과 상표

AI가 만든 이미지라고 해서 저작권과 상표 문제가 자동으로 사라지지 않습니다. 특정 작가의 고유한 스타일, 유명 캐릭터, 실제 브랜드와 로고를 모방하도록 요청하지 않습니다. 외부 배포 전에는 조직의 권리 검토 절차를 따릅니다.

### 10.4 시각적 완성도

* 손, 얼굴과 물체의 형태가 자연스러운가?
* 원근, 반사, 빛과 그림자가 일관적인가?
* 작은 글자와 숫자가 정확한가?
* 요청하지 않은 로고, 워터마크와 인물이 없는가?
* 원본에서 유지해야 할 요소가 바뀌지 않았는가?

## 11. 자주 막히는 문제와 해결 방법

| 문제 | 원인 | 해결 방법 |
| --- | --- | --- |
| 전체 이미지가 크게 바뀜 | 유지 조건이 부족함 | 변경·유지·제외 항목을 분리하고 한 번에 한 요소만 수정 |
| 선택하지 않은 영역도 바뀜 | 선택 영역은 편집 경계가 아니라 참고 범위일 수 있음 | 위치를 자연어로 다시 지정하고 유지 조건을 반복 |
| 얼굴이나 제품이 달라짐 | 반복 편집으로 변화가 누적됨 | 원본에서 다시 시작하거나 핵심 참조 이미지를 다시 첨부 |
| 새 요소가 공간에 어울리지 않음 | 원근과 광원 조건이 없음 | 카메라 각도, 광원, 그림자와 재질 일치를 요청 |
| 글자나 로고가 생김 | 제외 조건이 누락되거나 충분히 반영되지 않음 | 금지 항목을 다시 명시하고 최종 결과를 직접 검수 |
| 편집 기능이 보이지 않음 | 앱·버전·플랜 또는 화면 차이 | 생성 이미지를 열거나 참조 이미지를 첨부한 뒤 현재 제공되는 편집 동작 확인 |

## 12. 실습 완료 기준

* 사용 권한이 있는 이미지를 준비했습니다.
* 편집 전에 피사체, 배경, 구도, 조명과 유지 요소를 분석했습니다.
* 변경할 요소와 유지할 요소를 분리해 요청했습니다.
* 오른쪽 벽면 외의 인물, 구조, 조명과 비율이 유지됐는지 확인했습니다.
* 원근, 그림자, 텍스트와 로고를 검수했습니다.
* 수정이 필요하면 한 번에 한 요소만 다시 요청했습니다.
* 실제 데이터, 인물, 저작권, 상표와 보안 위험을 점검했습니다.

## 13. 핵심 정리

* 부분 편집은 전체를 다시 만드는 작업과 다릅니다.
* 바로 수정하기 전에 원본 구조와 유지 요소를 분석합니다.
* 편집 요청에는 대상, 변경, 유지와 제외 조건을 넣습니다.
* 선택 도구를 쓰더라도 자연어로 영역과 유지 조건을 함께 설명합니다.
* 원본과 편집본을 나란히 비교하고 작은 수정으로 개선합니다.
* 실제 수치와 사건을 보여 주는 자료는 생성 이미지로 대체하지 않습니다.
* 외부 사용 전 사실성, 시각적 오류, 인물, 권리와 보안을 사람이 검수합니다.

현재 이미지 편집 방법과 프롬프트 원칙은 [OpenAI 이미지 생성 공식 가이드](https://learn.chatgpt.com/docs/image-generation)에서, 첨부 이미지 분석 방법은 [OpenAI 이미지 입력 공식 가이드](https://learn.chatgpt.com/docs/image-inputs)에서 확인할 수 있습니다.
